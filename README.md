# 胃安 · 胃部不适先分清轻重

一个纯前端、可离线运行的中文健康自测网站。它先做急诊红线筛查，再根据中医“十问”思路收集线索，结合人体部位图、舌面手诊照片、发质指甲等观察，最后列出最值得关注的常见情况和可能的中医证型。

> **重要说明**：这是一个健康教育工具，不是医疗器械，也不构成诊断、处方或治疗建议。出现剧烈腹痛、呕血、黑便、胸痛、晕厥等情况，请立即拨打 120 或前往急诊。

> **目录说明**：本文件夹 `胃安网站` 就是完整网站，可整体复制、移动或部署；入口是文件夹内的 `index.html`。

## 立即运行

方式一：直接用浏览器打开 `index.html`。项目没有构建步骤，也不依赖网络。

方式二：在本文件夹内启动一个静态服务器：

```powershell
python -m http.server 8787 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8787/`。

> **摄像头提示**：浏览器通常只在 `localhost` / `127.0.0.1` 或 HTTPS 页面开放摄像头权限。用 `file://` 直接打开时，若无法调用摄像头，仍可使用“上传照片”或直接跳过。

## 功能流程

1. **急诊分诊**：8 组危险信号，包括突发剧烈腹痛、呕血/黑便、胸痛大汗、腹部板硬、高热黄疸、脱水、晕厥、孕期腹痛。
2. **紧急处理页**：明确提示拨打 120，给出等待救援时的安全措施（停止进食进水、舒适体位、松解衣领、留人陪伴、准备就医信息），并列出“不要做”的事项。
3. **六组问诊**：按“十问”思路重组为
   - 基本信息与病史：**生理性别、具体年龄、体型**、既往史、用药、家族史、孕期/哺乳
   - 身体哪里不适：**最主要的感觉可多选**，在精细人体图上点选部位，病程、牵连部位（可多选）、程度
   - 问题总结：**用一句话总结最困扰的问题**，再补充进食关系、反流、胃口和诱因
   - 二便与全身
   - 舌面手诊：**摄像头拍舌象 / 面部 / 手掌**，或上传照片；新增**掌色、大鱼际、手心温度与手汗、青筋、手部警示征象**和手诊分区参考
   - 发甲与情绪：**发质、指甲、牙龈、眼底、情绪、睡眠**（眼底需眼科检查，没有结果可跳过）
4. **规则分析**：对 9 类常见情况进行加权匹配，并给出就医优先级。
5. **中医证型**：在原有 8 种证型基础上增加“气血两虚”，并把舌形、舌下络脉、面色、光泽、眼周、口唇、发质、指甲、牙龈、掌色、大鱼际、手温等纳入评分；眼底异常和手部红旗征象会提示就医评估。
6. **结果页**：最需要关注的情况、另外两种可能、中医证型、望诊记录、下一步节奏、必须就医的信号。
7. **其他**：手机端适配、键盘操作、打印/保存结果、无网络请求、无数据持久化。

## 分析逻辑

`app.js` 中的核心数据：

- `TRIAGE_FLAGS`：急诊红线。
- `BODY_LOCATIONS`：人体图上的 6 个具体区域 + “整个肚子 / 说不清”。
- `QUIZ_STEPS`：六组问题及选项。
- `CONDITIONS`：9 类常见情况的说明、建议和警示信号。
- `PATTERNS`：9 种中医证型的说明与调理方向。
- `score*()`：每类情况和每种证型的加权规则。
- `evaluateUrgency()`：根据症状、年龄、病程、警示信号决定“立即急诊 / 24 小时内 / 1–2 周内 / 先观察”。

结果页的“线索匹配程度”是规则匹配分，**不是患病概率**。排序只表示“在这套问卷的线索下，哪类情况更值得先考虑”，不能替代医生面诊和检查。

### 修改或扩展

- 想改问题：编辑 `QUIZ_STEPS`，并在 `DEFAULT_ANSWERS` 中补上对应字段。
- 想改人体图：编辑 `BODY_LOCATIONS` 和 `renderBodyMap()` 中的 SVG 区域坐标。
- 想改可能性排序：调整对应 `score*()` 中的权重，或修改 `CONDITIONS` 文案。
- 想增加新的情况：新增 `CONDITIONS` 条目、评分函数，并把评分函数加入 `buildAnalysis()`。
- 想改中医证型：编辑 `PATTERNS` 与 `scoreCold` / `scoreDampheat` 等函数。

## 摄像头与照片

- 使用浏览器 `getUserMedia`，在用户点击“开启摄像头”后才请求权限。
- 拍照或上传后，图片会被限制到最大 900px，并以 JPEG data URL 保存在当前页面内存中。
- 照片不会上传、不会写入 localStorage，刷新或重新开始即清除。
- 摄像头只用于“拍下来自己对照观察”，**不做人脸识别、舌象/手象自动识别或自动诊断**。
- 页面提供“上传照片”和“直接跳过”作为无摄像头 / 拒绝授权时的替代路径。

## 医疗安全设计

- 急诊红线优先于问卷：只要勾选任意一项，就进入紧急处理页，不继续收集问卷。
- 问卷中再次拦截黑便/血便：选择后立即出现就医警告。
- 年龄、体重下降、吞咽困难、家族史等“报警症状”会提高就医优先级，并单独显示“需要排除”卡片。
- 不推荐具体处方、中药剂量或自行用药；只给生活调整、就医方向和检查方向。
- 所有问诊数据与照片只在当前页面内存中，刷新即清除，不上传服务器。
